Обновлять по мере снятия блокеров: менять статус пункта, добавлять указатель на
живое доказательство (commit/скриншот/запись прогона). Когда все 11 пунктов ✅ и
блокеры A–D закрыты — переносить содержимое в финальный `docs/release/v1.0-dod.md`
как эталонную запись гейта G4 и публиковать Release `v1.0.0`.
